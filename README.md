## 📌 Project Overview

Urban and riverine flooding causes massive socio-economic losses every year. This project provides a centralized dashboard to:
1. **Track water levels & rainfall trends** across sensitive regions.
2. **Visualize flood-prone zones and hazard heatmaps** using interactive maps.
3. **Dispatch early warnings & evacuation guidance** to vulnerable communities.
4. **Coordinate resource allocation & rescue operations** during emergencies.

---

## ✨ Key Features

- **🗺️ Interactive Flood Inundation Maps:** Dynamic mapping displaying high-risk zones, water drainage routes, and real-time sensor/weather overlays.
- **📈 Predictive Analytics & Water Level Tracking:** Monitoring rainfall metrics, river discharge, and alert thresholds.
- **🚨 Automated Alert & Notification System:** Categorized warning levels (Advisory, Watch, Warning, Evacuate).
- **🛡️ Safe Route & Shelter Finder:** Geospatial routing to nearby relief centers, higher ground, and emergency response hubs.
- **📊 Reporting & Resource Management:** Citizen hazard reporting and administrative tools to manage response resources.
- **📱 Responsive & Accessible UI:** Optimized for desktop command centers as well as mobile devices during fieldwork.
